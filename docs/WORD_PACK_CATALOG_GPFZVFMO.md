# Word pack catalog: GpfzVfMO

The catalog is stored in `product_gotit.word_topics`, `word_tracks`,
`word_packs`, and `word_pack_entries`. A pack belongs to one directed
`source_language_code` → `translation_language_code` track. User installation,
item links, and learning progress refer to stable pack and entry UUIDs.

The two pre-existing seed migrations provide 6 topics, 12 tracks, 19 packs,
and 228 entries, all **English → Hebrew**. The new migration adds 3 topics
(colors, animals, household items), 5 intermediate tracks in existing topics,
11 packs, and 54 entries. The resulting catalog has 9 topics, 20 tracks,
30 packs, and 282 entries, still English → Hebrew. Business, sports, and
household items now each have two units at the expanded level.

The new pairs were checked individually against matching English/Hebrew
[Wiktionary entries](https://en.wiktionary.org/). For ambiguous words, the
chosen sense is concrete and narrow: `orange` is the color, `goal` is a sports
score, and `invoice` is a commercial bill. The English entry for
[`policy`](https://en.wiktionary.org/wiki/policy) and Hebrew entries for
[`survey`](https://en.wiktionary.org/wiki/%D7%A1%D7%A7%D7%A8),
[`expense`](https://en.wiktionary.org/wiki/%D7%94%D7%95%D7%A6%D7%90%D7%94),
and [`payment`](https://en.wiktionary.org/wiki/%D7%AA%D7%A9%D7%9C%D7%95%D7%9D)
resolve gaps in the English translation tables. Example sentences were left
empty because none were separately reviewed.

The product language picker exposes 29 language codes, including regional
Portuguese and Chinese variants. The interface itself has 8 translations.
Neither set means that word-pack translations exist for those languages.
For every learning direction other than English → Hebrew, content still needs
editorial translation and sense review. In particular, the Hebrew → English
direction is not generated by swapping columns: morphology and sense can
change, and existing IDs or progress must not be repurposed.

The migration only inserts new UUIDs. It does not update prior packs, entries,
or user tables. Its rollback refuses to delete any newly installed pack with
user links. Integration tests load the catalog with English → Hebrew and verify
empty results for each other offered source or target language, so the UI never
mislabels English/Hebrew content as translated content.
