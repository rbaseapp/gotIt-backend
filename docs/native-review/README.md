# בדיקת טבעיות: הנחיות לבודקים

תודה שאתם עוזרים. אתם קוראים את האנגלית שהלומדים שומעים וקוראים, ומסמנים כל דבר שדובר אמריקאי לא היה אומר ככה. לא צריך ידע בהוראה. מספיקה אוזן של מי שמדבר אנגלית שוטפת.

## מה עושים
1. פותחים את `review-sheet.csv` ב־Google Sheets (קובץ ← ייבוא) או ב־Excel.
2. כל אחד לוקח רמה אחת (עמודה `level`) וכותב את השם שלו בעמודה `reviewer`.
3. לכל שורה כותבים בעמודה `verdict` אחת משלוש אפשרויות:
   - `ok`: נשמע טבעי.
   - `fix`: לא טבעי. כותבים בעמודה `suggested_english` איך הייתם אומרים את זה.
   - `unsure`: לא בטוחים. מוסיפים הסבר קצר בעמודה `comment`.

## מה בודקים
- **האם אמריקאי היה אומר את זה ככה, בשיחה רגילה?** בשורות מסוג `dialogue` ו־`teacher example` זה דיבור, וצריך להישמע כמו דיבור. בשורות מסוג `reading passage` זה טקסט כתוב, ושם מותר ניסוח מעט רשמי יותר.
- **האם המילה בעמודה `word` משמשת במשמעות שבעמודה `meaning_he`?** זה רלוונטי לשורות מסוג `teacher example`.
- **האם יש מילה בריטית** (flat, queue, holiday) **או איות בריטי** (colour, centre)? אם כן, מסמנים `fix`.
- **מה לא בודקים:** רמת הקושי. היא נמדדת אוטומטית.

## סדר עדיפויות
1. **שורות מסוג `teacher example`:** אלה 266 המשפטים החדשים ביותר, ועוד אף אחד לא קרא אותם.
2. **רמות Pre-A1, ‏A1 ו־A2:** לשם יגיעו המתחילים בפיילוט ראשונים.
3. **כל השאר.**

רמה אחת לוקחת בערך שעה. הקובץ נוצר מחדש מהתוכן העדכני בפקודה `npm run export:review`.
